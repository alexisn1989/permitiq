    Data sources & methodology

    PermitIQ republishes normalized public permit records from each city's own open-data system. The original agency record is always authoritative — if something here looks wrong, check the source link on that city's card below. Some records lack map coordinates (their address didn't resolve to a location yet, or isn't a mappable street address at all); missing data does not mean no permit exists. Permit types and statuses use each city's own vocabulary, so the same word can mean different things in different cities. Chesapeake and Portsmouth have real permit systems but no confirmed open dataset yet; Hampton, Suffolk, and Newport News are not yet covered at all.
